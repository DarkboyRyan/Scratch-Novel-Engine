# Examples

[中文](./README.md) | [English](./README.en.md)

[Parent directory](../README.en.md)

These small Author projects open directly in Editor and demonstrate editing workflows and historical format compatibility.

- [Hello Project](./hello-project/README.en.md): a minimal Author v1 project for testing reading, in-memory migration, and saving as current v22.

Start Editor, choose “Open Project,” and select an example directory. Copy the entire directory before editing or saving to preserve the historical input in the repository. Runtime v13 exports take their default language from Editor settings without translating author text.

Keep examples small and paths portable. Exclude exported bundles and local absolute paths. Cover complex edge cases with automated tests.

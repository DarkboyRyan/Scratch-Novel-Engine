这些小型 Author 工程可直接在 Editor 中打开，用于了解编辑流程和验证历史格式兼容性。

- [Hello Project](./hello-project/README.md)：最小 Author v1 工程，验证读取、内存迁移和保存为当前 v22。

启动 Editor，选择“打开项目”，再选择示例目录。编辑或保存前先复制整个目录，保留仓库中的历史格式输入。导出为 Runtime v13 时，默认语言来自 Editor 设置，不会翻译作者文本。

示例保持体积小、路径可移植，不包含导出包或本机绝对路径。复杂边界使用自动测试覆盖。
